# You Will Stop Burning Your AI Credits After Watching This (3 Tips)

## Final Result

A short mockumentary about three animals living and working among people: a bear waiting tables, a chimp on a construction site, and a deer delivering parcels. Each claims life with humans is fine. Then we see their day. Made cheaply with reusable Elements and credit-saving tests in 480p.

## Skill Installation

The acting skill turns plain notes into ACTING TASK blocks in video prompts: GOAL, MOTIVE, OBSTACLE, TACTIC.

1. Download higgsfield-acting-skill.zip from the skill page.
2. In Claude: Customize → Skills → + → upload the zip.
3. Open a new chat so the skill activates.

Keep Element names (@bear, @chimp, etc.) identical in Claude and Higgsfield.

Use Cinema Studio project with folders: CHAR, PROPS, LOCATION, SCENES.

Images: Seedream 5.0 Pro and Soul Cinema. Videos: Seedance 2.5.

## Step-by-Step Recreation Playbook

1. Create Cinema Studio project with CHAR, PROPS, LOCATION, SCENES folders.
2. Install acting skill in Claude.
3. Generate character sheets for @bear, @chimp, @deer using the Claude requests and Seedream 5.0 Pro. Save as Elements.
4. Generate separate outfit sheets. Edit if needed. Save as Elements.
5. Build locations with palette card attached to Claude. Save as Elements.
6. For each scene, use Claude with acting skill to expand simple notes into full video prompts with ACTING TASK. Attach relevant Elements.
7. Test in 480p draft mode. Fix details or use Object Swap instead of full regenerates.
8. Generate final in Seedance 2.5 at higher res only for kept takes.
9. Assemble the film.

## Key Learnings & Replication Notes

Test every shot in 480p first. Fix single details instead of regenerating whole scenes. Use Object Swap to test new characters cheaply. Acting skill reduces retries by giving every action a reason. Keep Elements consistent. Voice trials are cheap and iterative. One of the cheapest films because of these steps.
