## Final Result
End-to-end marketing agency workflows (100-piece UGC campaign, cinematic long-form film, full branded website) run from single prompts inside Higgsfield Supercomputer.

## Skill Installation
No separate skill file — Supercomputer ships with built-in skills and model orchestration. Simply use the Supercomputer interface / MCP.

## Complete Prompt Library
Single high-level prompts are enough. Examples of the three demonstrated workflows:
- “Create a 100-piece UGC ad campaign for [product]”
- “Generate a cinematic long-form film about [topic]”
- “Build and launch a complete branded website for [business] with the following structure…”

## Step-by-Step Recreation Playbook (for an AI Agent)
1. Open Supercomputer (or connect via MCP).
2. Give one clear outcome prompt.
3. Let the orchestrator choose models, write prompts, generate assets, and assemble.
4. Review and iterate only the parts that need human taste.

## Key Learnings & Replication Notes
- Supercomputer removes the need to manually route between models and tools.
- The highest leverage is clear outcome specification, not micro-prompting.
