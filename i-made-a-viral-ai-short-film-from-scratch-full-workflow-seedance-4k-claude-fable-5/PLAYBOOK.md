## Final Result
A multi-world action-comedy short film in 4K where one consistent character travels through pirate ship → desert ostrich chase → jungle → modern apartment twist, all generated with Seedance 2.0 and locked assets.

## Skill Installation
1. Download `higgsfield-seedance-prompt.skill`
2. Claude → Customize → Skills → Upload
3. Use the skill to turn scene ideas into production-ready Seedance prompts with continuity locks.

## Complete Prompt Library
- Create 3-view character sheets on mid-grey backgrounds with exact identity, scar, costume, and lighting locks.
- Generate location and prop sheets the same way.
- Every video prompt must carry the full style block + positive locks + @references.

(Full multi-part scene prompts for ship explosion, desert chase, jungle sequences, and apartment twist are on the source page.)

## Step-by-Step Recreation Playbook (for an AI Agent)
1. Install skill.
2. Build locked asset sheets for the hero, every location, and key props.
3. Write a short script that jumps worlds via continuous action or hard cuts.
4. Feed each scene into the skill.
5. Generate in Seedance 2.0 4K / 21:9 with positive locks enforced.
6. Assemble the continuous narrative.

## Key Learnings & Replication Notes
- One character + multiple extreme worlds is the strongest “wow” structure.
- Grey sheets + face erase + positive locks = consistency across completely different environments.
- Continuous shots with real physics sell the transitions.
