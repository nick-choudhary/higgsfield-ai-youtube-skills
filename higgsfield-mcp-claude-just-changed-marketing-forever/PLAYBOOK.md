# PLAYBOOK: Higgsfield MCP + Claude Just Changed Marketing Forever!

**Source Video:** https://www.youtube.com/watch?v=l7W3QzU8w5s  
**Skill File:** `higgsfield-content-factory.skill` (Dropbox link in original description)

## Final Result
Hundreds of UGC-style ads generated from a single product image, fully planned and produced inside one Claude chat, then scheduled to Meta Ads, with matching static asset packs.

## Skill Installation
1. Download `higgsfield-content-factory.skill` from the Dropbox link in the video description.
2. Claude → Customize → Skills → Upload
3. Connect MCP: `https://mcp.higgsfield.ai/mcp`

## Complete Prompt Library
The skill drives the entire pipeline. Typical flow commands:
- Research trends on TikTok / Instagram / YouTube
- Build content plan
- Generate multi-format UGC videos (Marketing Studio)
- Create static image pack with GPT Image 2.0
- Schedule to Meta Ads

## Step-by-Step Recreation Playbook (for an AI Agent)
1. Install skill + connect MCP.
2. Provide one product image + brand brief.
3. Let the skill run research → content plan → video generation → static pack.
4. Review and approve batches.
5. Push approved creatives to Meta Ads.

## Key Learnings & Replication Notes
- One product image is enough to generate dozens of on-brand UGC variations.
- The skill handles format diversity (different hooks, lengths, styles).
- Closing the loop with Meta Ads scheduling turns generation into distribution.
