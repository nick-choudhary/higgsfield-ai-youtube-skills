## Step-by-Step Recreation Playbook
1. Generate character sheet for the human subject using the Nano Banana 2 prompt. Attach reference logo image if available. Save as @adil-hiking or equivalent.
2. Generate dragon character sheet using the Seedream prompt. Save as @dragon_v1.
3. For video-to-video shots: Upload source clip as @video1. Run the replacement prompt in Seedance 2.5. Match scale and motion exactly.
4. For pure generation shots: Build location references first (cave, waterfall, cliff). Use size-fit frames to lock scale between rider and dragon.
5. Assemble continuous one-take prompts with the full style + physics + continuity block at the top. Specify exact timing in seconds for actions and camera locks.
6. Iterate failed generations by spotting identity drift or physics breaks early. Re-generate only the broken segment with tighter positive locks.
7. Composite final sequence offline if needed for the side-by-side or short film. Keep original AI outputs unedited where possible.
8. Compare frame-by-frame against traditional VFX reference for validation.

## Key Learnings & Replication Notes
- Character sheets lock face, hair, wardrobe, and proportions across generations. Use three-angle layouts.
- Size-fit frames prevent scale drift between subjects and creatures.
- Positive locks (what must stay identical) outperform negative instructions.
- Continuous unbroken shots require hard camera endpoints and exact second-by-second action timing.
- Seedance 2.5 handles fluid physics, motion blur, and long takes better than prior versions in the tested categories.
- No green screen or 3D software required. All work stays inside Higgsfield + Claude for prompt writing.
- Credits burn fast on long complex shots. Spot slop early.
