# PLAYBOOK: 5-Step Workflow To Make Ultra-Realistic AI Short Films (Seedance 2.0 4K)

**Source Video:** https://www.youtube.com/watch?v=HSON-SoFz7s

## Final Result
A 1-minute hyper-realistic short film in native 4K Seedance 2.0 that mixes fantasy, wildlife documentary, post-apocalyptic chase, and epic battle sequences, all watched by a character on a TV, with consistent assets and documentary-style realism.

## Skill Installation
1. Download `prompt-writter.skill`
2. Claude → Customize → Skills → Upload
3. Connect Higgsfield MCP if using agent mode
4. The skill writes production-ready Seedance prompts from scene descriptions.

## Complete Prompt Library
Use the skill to generate prompts. Key asset creation pattern from the workflow:

- Build all characters, locations, and props first on neutral grey backgrounds.
- Reference them with @tags in every video prompt.
- Apply the same style lock across all scenes (8K IMAX / photoreal / natural light / diegetic audio only).

(Full multi-scene prompt library lives on the skill page. The skill itself produces the shot-by-shot versions.)

## Step-by-Step Recreation Playbook (for an AI Agent)
1. Install the skill.
2. Create locked grey-background asset sheets for every recurring character, location, and prop.
3. Write or generate a short script that moves the camera through multiple visual worlds via a TV device.
4. Feed each scene description into the skill → receive Seedance-ready prompts.
5. Generate in Seedance 2.0 at 4K, enforcing positive locks and the global style block.
6. Assemble the final minute with hard cuts and the TV framing device.
7. Add documentary-style voiceover if needed.

## Key Learnings & Replication Notes
- Grey background assets are the single highest-leverage consistency technique.
- 4K holds detail in wide shots where 1080p collapses.
- The TV framing device allows wild world jumps while keeping the main character locked.
- Always iterate individual shots rather than regenerating entire sequences.
