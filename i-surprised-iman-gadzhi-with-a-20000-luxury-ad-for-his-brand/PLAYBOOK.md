## Step-by-Step Recreation Playbook

1. Connect Higgsfield MCP to Claude as described above.
2. Download and load the prompt-writing skill and lens-transition skill.
3. Generate asset references: lead character sheet with Seedream 5.5, supporting cast with Soul 2.0 using the provided prompts. Use own product photos for glasses.
4. Build location plates (e.g., Westminster Bridge with specific car placement via Seedream edit).
5. Generate Scene 1 video with Seedance 2.5 using the long prompt and attached references. Talk to Claude in plain language; it writes the detailed prompt.
6. Generate remaining scenes (2-9) the same way: assets + video prompt via MCP.
7. Use the lens transition VFX skill in Claude Code to connect shots (e.g., London final into girls scene through glasses reflection).
8. Fix product details (engraved silver, HILLS logo) in Claude Code while preserving face, lighting, and transitions.
9. Assemble final commercial in Claude. Preview in chat if possible. No external editor required.

## Key Learnings & Replication Notes

- Talk to Claude like a person. It writes the full technical prompts.
- Specify models explicitly: Soul 2 for characters, Soul Cinema for locations, Seedream 5.5 for references/edits, Seedance 2.5 for video. Keep 16:9.
- Lock identity, wardrobe, and product details with strong reference images and negative constraints.
- Lens transitions via code give control without traditional VFX software.
- Download the skills before starting. Use them for prompt shaping and shot connections.
- Swap product and character for your own commercial.
