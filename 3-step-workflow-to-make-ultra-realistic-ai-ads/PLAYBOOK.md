## Skill Installation
1. Download `higgsfield-seedance-shotlist-director.skill`
2. In Claude: Customize → Skills → Upload the skill file
3. Connect Higgsfield MCP: Settings → Connectors → Add → paste `https://mcp.higgsfield.ai/mcp`
4. The skill writes shotlists + per-scene Seedance 2.0 prompts in the exact format the model expects.

## Step-by-Step Recreation Playbook (for an AI Agent)
1. Install the skill and connect MCP.
2. Generate all assets first on neutral grey backgrounds (product sheet → character sheets → location sheets → props). Use the exact prompts above.
3. Run the face-erase edit on any multi-face sheets.
4. Feed the script + asset tags into the Claude skill. It will output Seedance-ready shotlists.
5. Generate each scene in Seedance 2.0 4K, referencing the locked assets with @tags.
6. Enforce the Positive Locks and style block on every generation.
7. Iterate only the failing shots; do not regenerate the whole sequence.

## Key Learnings & Replication Notes
- Grey background character/location sheets dramatically raise consistency win rate.
- Always erase extra faces from multi-view sheets.
- Positive Locks are non-negotiable for identity, wardrobe, and blocking.
- Style block (8K IMAX, natural light only, pore-level skin, Hollywood acting, diegetic audio only) must be repeated on every scene.
- 3/4 angle locations give the camera room to move without breaking continuity.
- The skill exists specifically so you never hand-write Seedance shot descriptions.
