## Step-by-Step Recreation Playbook

1. Build and lock every asset first. Generate three-panel character sheets with Seedream 5.0 Pro. Apply the hybrid face trick. Create clean location plates in Soul Cinema. Draw the scale sketch and any storyboards needed for spatial problems.
2. Save each asset as a named Higgsfield Element. Use the exact names the skill expects (@Nate_cruise, @giant, etc.).
3. Upload the Claude skill.
4. Open a fresh Claude chat. Attach the script and every locked asset. Give the element list so names match.
5. Describe each scene in plain language the way you would tell a friend. Let the skill return the full Seedance prompt with reference definitions, technical block, and shot list.
6. Paste the prompt into Cinema Studio. Generate in Seedance 2.5. Keep the same style header across all scenes.
7. Split any sequence that is too long for one generation (fight vs acting, boarding vs duel).
8. Batch several takes per scene. Stitch the cleanest frames in the edit.
9. Attach the voice-memo audio reference only on the elevator scene so the hummed melody stays in key.
10. Swap the real photos and the film becomes a custom piece for any couple.

## Key Learnings & Replication Notes

- Assets first. Consistency lives in the stills, not the video model.
- Hybrid face method solves the lookalike problem: keep generated body and costume, paste real portrait.
- Scale sketches and storyboards stop the model from breaking height and spatial logic.
- Bake crowds into the location plate so background extras never turn to mush.
- Split overloaded sequences. One focused generation beats one overloaded prompt.
- Reuse the identical technical/style header across every era so the six pieces feel like one film.
- Audio reference is the only reliable way to keep a hummed melody on pitch.
- The skill does the heavy prompt work. Your job is clean assets and clear scene descriptions.
