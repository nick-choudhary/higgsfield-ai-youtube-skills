## Step-by-Step Recreation Playbook

1. Create a Cinema Studio project. One folder per scene.
2. Build character references for the three roles. Use front, rear, and face panels. Lock clothing and faces.
3. Generate location plates and any props. Save each as a named Element.
4. Load the skill into Claude.
5. For each scene, describe the action, camera, and continuity. Attach the relevant Elements. Copy the returned prompt into Seedance 2.5.
6. Generate multiple takes. Compare failures against successes. Fix with tighter framing, explicit shot counts, or asset swaps.
7. Edit the selected clips into the final commercial.

## Key Learnings & Replication Notes

- Spend the time on assets before video generation. Consistency comes from the stills.
- Direct scenes with clear shot lists. Wide open prompts produce drift.
- Compare every take. Keep the ones that hold the characters and motion.
- The same three-step loop (assets, setup, generation) scales to other products.
- Full prompt text is on the linked skill page. Do not reconstruct from memory.
