# Final Result

Cinematic AI short film built in two days with Claude, Seedance 2.5, and Higgsfield Cinema Studio. Covers character consistency, fight scenes, acting, and final assembly.

Use Claude with the Higgsfield prompt skill (Hixel prompt skill), scene skill, fight skill, and acting skill (Higgsfield acting skill).

Attach the skill to a scene brief. The skill expands direction into shots, camera moves, dialogue, and timing.

# Complete Prompt Library

Complete copyable prompts live on the linked Higgsfield page. Do not re-host binary files.

Key usage patterns from the tutorial:

- Scene skill: turn a brief into structured shots with camera, action, and dialogue.
- Fight skill: list who is where, what each character does, and how each hit lands. The skill supplies physics and reactions.
- Acting skill: build performance around what each character wants from the other. Provide exact lines and camera rules.

Element names used in the project: @char_adam_video_v1, @char_ron_video_v1, @char_victor_video_v1, @loc_alley_v1, @loc_room_ron_v1. Keep names identical in Claude and Higgsfield.

# Step-by-Step Recreation Playbook

1. Create a Cinema Studio project. Use one folder per scene. Subfolders for characters, locations, and props.
2. Build characters as video Elements. Start Adam from a photo. Generate variations in GPT Image 2.5. Clean skin, hair, and fabric in Cream using reference shots.
3. Cast supporting characters in Soul Cinema. Turn approved stills into video Elements. Add short voice recordings of natural tones.
4. Generate location plates with fixed lenses (24mm anamorphic, 35mm). Use 3/4 angles for depth.
5. Write scene briefs. Attach the prompt skill in Claude. Request shots, camera moves, and dialogue. Attach the matching Element names.
6. Generate drafts in Seedance 2.5 at 480p. Check framing and positions. Keep useful takes. Recreate selected takes at 1080p.
7. For fights, list the action sequence. Feed the list to the fight skill. Specify foot placement, guard drops, and impact reactions.
8. Combine takes. Hide cuts on movement or whip pans. Use Cinema Studio Extend to add seconds. Relight finished clips without regenerating.
9. Pull new angles from an existing take by uploading it as a video reference. Use overhead frames for blocking.
10. Assemble the final cut. Add B-roll from the extra prompts on the page.

# Key Learnings & Replication Notes

Video Elements beat image Elements for natural face movement and speech.

Draft at 480p to check blocking before spending credits on 1080p.

Write fights as concrete action lists. The model needs exact sequence, not style adjectives.

Lock Element names across tools. One name mismatch breaks consistency.

Room tours and video references let you generate new camera angles without rebuilding the set.

The film used named assets for Adam, Ron, and Victor. Victor’s wound is a separate image reference.

Extra bridge, club, and finale shots sit on the linked page and were not shown in the YouTube breakdown.
